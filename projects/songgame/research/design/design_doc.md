## 二、日循环（endDay 流程，按序）

1. **食宿扣费**：第 1–15 日 1 贯／日；第 16 日起 2 贯／日；考试日（exam）与放榜段（ending）1 贯。
   扣后 `money < 0` → 归零并 **失败：困于逆旅**。
2. **夜结算**（豁免场景：exam／ending／choice——即考试日、放榜段、长亭）：
   - 未维护的属性各 −1（maintained 由当日行动置位，见四）；
   - 精力 ≤2 时 **45% 概率病倒再 −1**（"夜里咳了起来"）；
   - 任一属性 ≤2 次日晨给 ⚠ 警告。
3. **失败判定**：智力 ≤0 胸无点墨；精力 ≤0 病卧逆旅；人缘 ≤0 孤身无援。
4. **推进**：日 +1；>30 → 结算结局。否则切换场景、行动点重置为 4、maintained 清空。
5. **赶路日**（kind=travel：山道 7–9、汴河 10–11 与 13–14）：行动点 −2（余 2），
   并掷一次 `travelEvent`（见五·丁）。
6. **enterDay 触发**：第 15 日城门开「门税」弹窗；第 12 日虹桥开「桥头」弹窗；
   考试日入 exam 相（第 25 日晨若有行卷且未回音 → 「行卷的回音」短笺）；
   此后 `maybeBandit`（第 8 日山匪／第 11 日水匪，各一次）→ `maybeEvent`（随机事件）。

## 六、题诗系统

- **十八题材**（随机抽，不与上次重复）：山川／赠友／故乡／父母／兄弟／勤学／
  场屋之忧／前程／报国／清贫／边事／生命／仕途／羁旅／民生／咏物／雅集／禅意。
  每题附示范诗（山川用王维《山居秋暝》、思乡用李白《静夜思》、父母用孟郊《游子吟》、
  报国用王昌龄《从军行》、民生用李绅《悯农》、咏物用王安石《梅花》等；清贫、雅集为拟作示范）。
- **判分（gradePoem，2026-11-04 拍板·四重标准·三档）**：**上品 ＝ 字数对齐 ＋
  非白话 ＋ 非默写 ＋ 切题**。齐整＝恰好四句且每句字数相同（不限五七言）；
  非白话＝不含白话字（们吗呢吧啊呀哦嗯咱呗挺很）／白话词（今天我们喝酒等
  31 词）／句末语助词（了的吗呢吧啊呀）；非默写＝任一句不与 18 首示范诗
  （`FAMOUS_LINES`）或**名句库**（`FAMOUS_EXTRA`，春晓/登鹳雀楼/春望/江雪/
  无题等约 60 句唐宋名句，标作者篇名）相同；切题＝含所投题材题眼字 ≥2
  （十八张题眼字表）。三项判别均为近似判断，如实声明。
  **三档**：上品——题诗 5 贯／鬻诗 4 贯＋智力 +1；**下品**（白话或默写，态度
  问题）——分文不给且**当众出丑人缘 −1**，评语冷；**中品**（离题或不齐，
  水平问题）——无酬，评语仍鼓励。注意：人缘 −1 计入夜结算死亡线——低人缘时
  当众出丑可能致"孤身无援"。用例入库：`poem_test.js` 八例全过
  （`osascript -l JavaScript poem_test.js`）。
- **一地一首**：题诗与鬻诗共享同一场景的一次机会（`poemUsed` 按场景 id）。
- **点缀不参与给分**：八韵部表（东阳支寒歌庚尤侵）标注韵脚；约三百字字类表
  （名动形色方代虚数）近似判对仗——"中二联相对"只写进评语。

  ```
  examPct   = 省试对题 / 15        palacePct = 殿试对题 / 3
  zhiCoef   = 0.60 + 智力/25      （智力 5→0.80，10→1.00）
  jingCoef  = 精力≥6 ? 1.0 : 精力≥3 ? 0.88 : 0.75
  score     = ( examPct×0.62×zhiCoef + palacePct×0.26
              + 人缘/10×0.12 + 传闻0.03 + 行卷0.02/0.04 ) × jingCoef
  ```
